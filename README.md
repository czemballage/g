# SUBJECT ZERO

تطبيق ويب (PWA) للإقلاع عن الإباحية، مبني كبروتوكول احتواء غامض بأسلوب شاشات الـ CRT والـ dot-matrix.

شاشة واحدة، وحش واحد، زر واحد:

- **العدّاد**: أيامك النظيفة.
- **الوحش الحالي**: كل ساعة تصمد فيها تختفي منه نقاط، ويموت حين تصل يومه (1، 3، 7، 14، 30، 60، 90، 180، 365).
- **زر «أشعر بالرغبة»**: دقيقة تنفّس مع دائرة، والوحش يتفكك مع كل نفَس.
- **سجّل انتكاسة**: العدّاد يرجع للصفر، والوحوش المقتولة وأفضل رقم تبقى.
- **شريط الوحوش**: من قتلت، ومن تواجه، ومن لا يزال مجهولاً.

كل البيانات محفوظة على الجهاز فقط (localStorage). لا حساب ولا خادم.

## التشغيل

ملفات ثابتة بلا build. افتح `index.html`، أو انشرها على أي استضافة HTTPS (GitHub Pages، Netlify…) ثم من المتصفح اختر «إضافة إلى الشاشة الرئيسية» لتعمل كتطبيق وبدون إنترنت.
