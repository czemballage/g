# SUBJECT ZERO

تطبيق ويب (PWA) للإقلاع عن الإباحية، مبني كبروتوكول احتواء غامض بأسلوب شاشات الـ CRT والـ dot-matrix.

- **العدّاد**: مدة صمودك بالأيام والساعات.
- **الكيانات**: 9 وحوش، كل واحد يحرس محطة (1، 3، 7، 14، 30، 60، 90، 180، 365 يوماً). طاقته تنزل كلما صمدت، ويسقط حين تصل يومه.
- **المواجهة (ENGAGE)**: حين تأتي الرغبة، يظهر كيان وتهزمه بأربع دورات تنفّس مربّع (4-4-4-4) مع أوامر عملية.
- **الإشارة اليومية**: تسجيل حالتك مرة يومياً.
- **الاختراق (BREACH)**: تسجيل الانتكاسة مع سببها. العدّاد يعود للصفر، لكن النقاط والكيانات وأفضل رقم تبقى.
- **الملف**: بطاقة الشخص، خريطة آخر 28 يوماً، مصادر الاختراق، والسجل.

كل البيانات محفوظة على الجهاز فقط (localStorage). لا حساب ولا خادم.

## التشغيل

ملفات ثابتة بلا build. افتح `index.html`، أو انشرها على أي استضافة HTTPS (GitHub Pages، Netlify…) ثم من المتصفح اختر «إضافة إلى الشاشة الرئيسية» لتعمل كتطبيق وبدون إنترنت.
